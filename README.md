# APM1205 Formative Assessment 4
## Dummy-Variable Regression Using Real-World Data

This repository contains my completed Formative Assessment 4 on dummy-variable regression using the `diamonds` dataset in R/RStudio.

### Files and folders

- `FA4_Dummy_Regression.R` — complete R code used for the assessment.
- `FA4_Dummy_Regression.pdf` — completed assessment with the answers, R output, regression analysis, and graph.
- `figures/` — contains the required graph/figure.
  - `diamond_price_vs_carat_by_cut.png`

### Analysis

The assessment uses:
- Response variable: `price`
- Quantitative explanatory variable: `carat`
- Categorical explanatory variable: `cut`
- Reference category: `Ideal`

The analysis includes dummy-variable coding, an additive regression model, an interaction model, an incremental F-test/ANOVA comparison, and a graph of diamond price versus carat by cut.

All analysis was completed using R/RStudio.
